#### Saved data

Everything Solitaire saves (CLAUDE.md: "Settings live in Redux", "Saves are per profile", "Personal par", "Records", "Settings follow the player"), and where each goes:

| Saved | Shape | On the package |
| --- | --- | --- |
| `solitaire:root` `theme` | auto-paper's settings: appearance, blur, a seed `color` with harmony `'triadic'` | the package's `theme`, the same reducer: as is |
| `haptic`, `sound`, `keepAwake` | feedback-press's and `@rific/core`'s | the package's: as is |
| `profiles` | `@tastic/profile`'s roster (the local copy of the App Group's) | the package's: as is |
| `lastActiveGame` | `{ gameId }` | the package's (mounted because the games are `resumable`): as is, the same ids |
| `activeProfile` | a profile id, or null for Guest | **reshaped** into `profileSelection`: `{ 1: id, 2: null }` |
| `tableColor` | `{ guestColor, profileColors }`, plus an `override` nothing reads | **reshaped** into `seatColors`: `{ lastGuestColor: { 1: guestColor ?? DEFAULT_SEED_COLOR, 2: seat 2's default }, lastCpuColor: seat 2's default, profileColors }` |
| `settings` | `Settings`, with `lockOrientation` and `lockedRotation` | stays the pack's; the lock **moves** to the package's `appSettings` (with `deferBottomEdgeGestures: false`) |
| `playerSettings` | by player (profile id or `'guest'`): settings, sound, haptic, Keep Awake, appearance and blur | the pack's, as is (filed `settings` keep their lock, which the middleware applies to `appSettings`) |
| `guide` | `{ versionSeen }` | the pack's (item 6), as is |
| `achievements` | `{ stats, unlocked }`, the stats with buckets by player, `'guest'` included | the pack's, as is |
| `recentWins`, `topWins` | by player, then variant | the pack's, as is |
| (new) `opponent` | `{ seatTwo }` | the package's default, unused until Ratscrew |
| `solitaire:gameInProgress.<id>`, eleven entries | by owner (a profile id, `'guest'` or the legacy `'saved'`): `SavedGame` | the pack's, each still its own entry, untouched (item 11's `blacklist`) |
| `solitaire.*` keys from before Redux | read only | still read only by `createReturningPlayerMigrate` |

Left alone, `createPackStore` would write `solitaire:root` with the package's keys and drop `activeProfile` and `tableColor` as keys no reducer has: every player back on Guest, every color pick and the lock gone, and every save copied into the root entry.

**Recommendation: keep the `solitaire:` prefix and reshape in place** with a migrate, not an import like PuckTastic's `importBoxHockey1.ts`. Only three keys change, and the package's other keys came from Solitaire with these names and shapes. An import would copy the saves (several MB) to new entries, leave the old ones in every web player's shared `games.infinitetoken.com` localStorage, and need a removal date. The rename keeps the bundle ID, slug, scheme and `/solitaire` path, so the prefix is no odder than they are. The migrate (`src/redux/shellMigrate.ts`) wraps the guide's: `async (state, version) => reshape(await returningPlayer(state, version))`. There's no persist version, so it runs on every launch: `reshape` acts only while the saved state has `activeProfile` or `tableColor` and no `profileSelection`.

**Rollback (Jay, 2026-10-29): the old keys stay for one release.** `activeProfile`, `tableColor` and `settings`' `lockOrientation`/`lockedRotation` stay in `solitaire:root`, held by reducers that only keep what they rehydrate, so an OTA rolled back to 1.2.8 finds each player, color pick and lock as they were at the move (anything changed after it is lost, nothing older). Rolling forward again reshapes again, since 1.2.8 drops the new keys on its next write. The release after drops the old keys.

**The native fingerprint.** No step needs a new build if item 2 holds: the package, split-screen, edge-guard and hud's `/lobby` are JS, Skia stays out (item 1), and edge-guard's plugin isn't added. What would change it: `@tastic/profile` 0.17, a patch bump of an Expo native module, Skia, or edge-guard's plugin. Check each step with `npx expo-updates fingerprint:generate` against 68be3d7's.
